# AI Stock Evaluator
Run locally with http://127.0.0.1:3000
An AI-powered stock research application that helps users analyze companies and generate investment research reports.

## Overview

AI Stock Evaluator provides an interactive interface for researching publicly traded companies. Users can submit research questions in natural language and receive AI-generated research based on financial information, market data, and external sources.

The project uses a separate FastAPI backend to handle the AI research pipeline.

## Features

- AI-powered stock research
- Company and stock analysis
- Natural-language research questions
- Multi-agent AI research
- External information gathering
- AI-generated research reports
- User authentication
- Saved research reports
- Web-based interface

## Architecture

The project is split into two repositories:

- Frontend: AI-stock-evaluator
- Backend: ai-stock-evaluator-backend

The frontend provides the user interface, while the backend handles authentication, AI research, external data gathering, and report storage.

## How It Works

1. A user submits a research question.
2. The frontend sends the request to the FastAPI backend.
3. The backend uses AI agents to research and analyze the question.
4. External sources are gathered to support the research.
5. The system generates a structured research report.
6. The report is returned to the user and can be saved for later.
